# Zettelkasten Method

The Zettelkasten (German for "slip box") is a knowledge management and note-taking method developed by German sociologist Niklas Luhmann.

## Core Principles

1. **Atomicity** - Each note should contain one idea and one idea only
2. **Autonomy** - Each note should be self-contained and understandable on its own
3. **Connectivity** - Notes should be linked to other related notes
4. **Unique Identifiers** - Each note has a unique ID for reference

## How It Works

Instead of organizing notes by topic in folders, the Zettelkasten creates a web of interconnected ideas. This mirrors how our brains actually work - through associations rather than hierarchies.

## Benefits

- Encourages [[Deep Work]] and focused thinking
- Builds a personal [[Knowledge Graph]]
- Supports [[Spaced Repetition]] through review
- Facilitates creative connections between disparate ideas
