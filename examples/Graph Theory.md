# Graph Theory

Graph Theory is a branch of mathematics studying graphs - mathematical structures used to model pairwise relations between objects.

## Definitions

- **Graph** - A set of vertices (nodes) connected by edges
- **Vertex/Node** - A point in the graph
- **Edge** - A connection between two vertices
- **Directed Graph** - Edges have direction (A → B)
- **Undirected Graph** - Edges go both ways

## Types of Graphs

### By Structure
- **Tree** - Connected graph with no cycles
- **DAG** - Directed Acyclic Graph (used in [[Git Basics]])
- **Complete Graph** - Every node connects to every other

### By Properties
- **Weighted** - Edges have values
- **Bipartite** - Nodes split into two groups

## Applications

Graph theory underlies many concepts:
- [[Knowledge Graph]] structures
- [[Linked Data]] in note systems
- Network analysis
- Route finding algorithms

## Key Algorithms

From [[Computer Science Basics]]:
- **BFS** - Breadth-First Search
- **DFS** - Depth-First Search  
- **Dijkstra's** - Shortest path
- **PageRank** - Node importance

## Metrics

- **Degree** - Number of connections
- **Path length** - Steps between nodes
- **Centrality** - Importance of a node
- **Clustering coefficient** - How grouped neighbors are
