# Plain Text Files

Plain text files are the simplest and most durable format for storing information digitally.

## Why Plain Text?

1. **Longevity** - Plain text from the 1970s is still readable today
2. **Portability** - Works on any operating system
3. **Simplicity** - No special software required
4. **Version Control** - Works perfectly with [[Git Basics]]
5. **Future-proof** - Will outlast any proprietary format

## Markdown

Markdown is a lightweight markup language that adds formatting to plain text:

```markdown
# Heading
**bold** and *italic*
- bullet points
[[wiki links]]
```

This is the preferred format for [[Zettelkasten Method]] implementations.

## The Unix Philosophy

Plain text aligns with the [[Unix Philosophy]]:
- Write programs that handle text streams
- Text is a universal interface
- Small, composable tools work together

## Use Cases

- [[Personal Knowledge Management]]
- Configuration files
- Documentation
- Source code
- Data interchange

## Character Encoding

Modern plain text uses UTF-8 encoding, which supports:
- All human languages
- Mathematical symbols
- Emoji (yes, they're valid UTF-8!)
