# Computer Science Basics

Computer Science is the study of computation, algorithms, data structures, and the principles underlying computer systems.

## Foundational Areas

### Algorithms

Step-by-step procedures for solving problems:
- **Sorting** - Organizing data (bubble sort, quicksort, mergesort)
- **Searching** - Finding data (linear, binary search)
- **Graph algorithms** - See [[Graph Theory]]

### Data Structures

Ways to organize and store data:
- **Arrays** - Contiguous memory, fast access
- **Linked Lists** - Dynamic, flexible size
- **Trees** - Hierarchical relationships
- **Hash Tables** - Key-value lookup

### Complexity Analysis

Big O notation measures efficiency:
- O(1) - Constant time
- O(log n) - Logarithmic
- O(n) - Linear
- O(n²) - Quadratic

Effective study requires:

## Key Principles

1. **Abstraction** - Hide complexity behind interfaces
2. **Decomposition** - Break problems into parts
3. **Pattern recognition** - See similarities across problems
4. **Algorithm design** - Create efficient solutions
