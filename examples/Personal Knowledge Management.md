# Personal Knowledge Management

Personal Knowledge Management (PKM) is a collection of processes for gathering, classifying, storing, and retrieving knowledge in daily activities.

## Core Activities

1. **Capture** - Collecting information from various sources
2. **Organize** - Structuring information for retrieval
3. **Distill** - Extracting key insights
4. **Express** - Using knowledge to create new things

## Methods

Several methodologies support PKM:

- [[Zettelkasten Method]] - Atomic, linked notes
- [[Spaced Repetition]] - For long-term retention
- [[Deep Work]] - For processing complex information

## Digital vs Analog

| Digital | Analog |
|---------|--------|
| Searchable | Tactile |
| Unlimited storage | Physical limits |
| Easy to link | Harder to connect |
| Backup concerns | Can't be "deleted" |

The best approach often combines both.

## Tools and Formats

For longevity, prefer:
- [[Plain Text Files]] with Markdown
- [[Linked Data]] through wiki links
- Local-first storage with cloud backup
- [[Git Basics]] for version history

## Building a Second Brain

PKM creates an external system that:
- Offloads memory burden
- Builds a [[Knowledge Graph]] over time
- Enables creative combination of ideas
- Supports lifelong learning
