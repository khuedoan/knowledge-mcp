# Linked Data

Linked Data is a method of publishing structured data so that it can be interlinked and become more useful through semantic queries.

## Origins

The term was coined by Tim Berners-Lee in his 2006 design note on the Semantic Web. The principles apply equally to personal knowledge systems.

## Four Principles

1. Use URIs (or unique identifiers) as names for things
2. Use HTTP URIs so people can look up those names
3. Provide useful information when someone looks up a URI
4. Include links to other URIs to enable discovery

## In Personal Notes

Applied to [[Personal Knowledge Management]]:

- Each note has a unique name (the filename)
- Wiki links (`[[Like This]]`) connect related concepts
- The [[Knowledge Graph]] emerges from these connections
- Bidirectional links show both directions of relationship

## Link Types

```
[[Direct Link]] - Simple reference
[[Concept|displayed text]] - Aliased link
#tag - Categorical marker
```

## Benefits

- **Serendipity** - Discover unexpected connections
- **Context** - Understand how ideas relate
- **Non-linear** - Navigate by association, not hierarchy
- **Emergent structure** - Organization arises from use

## The Web of Ideas

Just as the World Wide Web links documents, personal linked data creates a web of ideas. This supports the [[Zettelkasten Method]] principle of connectivity.
