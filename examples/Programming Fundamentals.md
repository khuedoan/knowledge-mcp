# Programming Fundamentals

Programming fundamentals are the core concepts that apply across all programming languages and paradigms.

## Core Concepts

### Variables and Data Types

Variables store data. Common types include:
- **Integers** - Whole numbers
- **Floats** - Decimal numbers  
- **Strings** - Text (stored as [[Plain Text Files]])
- **Booleans** - True/False values

### Control Flow

```
if condition:
    do_something()
else:
    do_other_thing()
    
for item in collection:
    process(item)
```

### Functions

Functions encapsulate reusable logic:
- Accept inputs (parameters)
- Perform operations
- Return outputs

### Data Structures

Essential structures covered in [[Computer Science Basics]]:
- Arrays/Lists
- Dictionaries/Hash Maps
- Trees (including [[Graph Theory]] applications)
- Graphs

## Learning Path

1. Start with one language deeply
2. Practice with [[Deep Work]] sessions
3. Build projects to solidify understanding
4. Document learning in a [[Zettelkasten Method]] system

## The Craft

Programming is both science and craft:
- [[Unix Philosophy]] - Simplicity and composability
- Version control with [[Git Basics]]
- Readable code as documentation

## Problem Solving

The fundamental skill:
1. Understand the problem
2. Break it into smaller parts
3. Solve each part
4. Combine solutions
5. Test and refine
